# Disney+ Review Sentiment Analysis

This repository contains a sentiment analysis pipeline for Disney+ application reviews using Text Mining and Machine Learning approaches (Multinomial Naive Bayes & SMOTE). The project is designed to run directly and conveniently in Google Colab.

## Folder Structure

Make sure you have the following main folder and its contents in your Google Drive:

```text
disney-plus-sentiment-analysis/
│
├── dataset/                  # Contains: data_disney.csv
├── kamus/                    # Contains: colloquial-indonesian-lexicon.csv
└── notebooks/                # Contains: disney+_sentiment_analysis.ipynb
```

## Instructions

1. Open Google Colab.
2. Click **File**.
3. Select **Open Notebook**, then choose the **Upload** tab.
4. Upload the notebook named `disney+_sentiment_analysis.ipynb` from your `notebooks` folder.
5. Run the notebook cells until you reach the **"Create Research Folder"** step.
6. Next, place the required files into the following folders in Google Drive:

```text
Analisis-Sentimen-Ulasan-Disney+/
│
├── dataset/                  # Place the raw dataset: data_disney.csv
└── kamus/                    # Place the lexicon file: colloquial-indonesian-lexicon.csv
```

7. Continue running the remaining notebook cells until the entire process is complete.

**Good luck! <3**
